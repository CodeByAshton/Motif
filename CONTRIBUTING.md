# Contributing

Bug reports and pull requests are welcome.

- For bugs, open an issue with the bug template. Your Obsidian version, OS, AI provider and steps to reproduce make it much easier to fix.
- For a pull request, run `npm test` and `npm run build` first. `npm run vault` puts your build into the sample vault in `My Book/` so you can try it in Obsidian.
- Bigger changes: open an issue first so we can talk about the approach.
- The end-to-end tests drive a real Obsidian; see [e2e/README.md](e2e/README.md).

Development needs Node 22.12 or newer.
